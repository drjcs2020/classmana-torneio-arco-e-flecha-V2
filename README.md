## Proteção da V1

Este repositório é independente. O jogo V1 e seu ranking no Railway não devem ser alterados.
A API online da V2 está intencionalmente DESATIVADA em `online-config.js`.
Antes de testar duelos online, implantar um serviço Railway V2 com banco SQLite e volume próprios.
As imagens de redesign V2 serão integradas em mudanças futuras, após revisão.

## Tecnologia

HTML, CSS, JavaScript, PlayCanvas Engine no navegador e Node.js com SQLite no backend `duel-api/`.
