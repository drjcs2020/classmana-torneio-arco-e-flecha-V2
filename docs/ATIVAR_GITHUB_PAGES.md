# Publicação do ClassMana Torneio de Arco e Flecha

Este repositório agora é independente do Painel das Casas.

**Endereço correto do jogo:**
https://drjcs2020.github.io/classmana-torneio-arco-e-flecha/

## Como habilitar o GitHub Pages

1. Abra https://github.com/drjcs2020/classmana-torneio-arco-e-flecha/settings/pages
2. Na seção **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)** e clique em **Save**.
4. Confira em **Actions** se a publicação terminou sem erro.
5. Abra o endereço do jogo. O arquivo `index.html` está na raiz.

### Se o navegador continuar mostrando conteúdo antigo
- Pressione Ctrl+F5 ou abra uma janela anônima.
- Confira o histórico de publicação em GitHub > Actions.
- Não use a URL antiga do Painel das Casas para testar o torneio.

## Placar Google Sheets

A configuração pública do Apps Script, se já informada pelo professor, está preservada em `online-config.js`.
O serviço permanece externo ao GitHub Pages e é compartilhado por todos os dispositivos.
A publicação do GitHub Pages não ativa automaticamente o Apps Script; ambos devem estar publicados.

**Privacidade:** não publique PINs, credenciais do professor ou cópias abertas da planilha.
